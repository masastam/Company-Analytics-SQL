# Company Analytics (MySQL)

Small practice project to model a company sales & employees database in MySQL.

Files:
- `schema.sql` – database schema (tables, foreign keys, ON DELETE rules).
- `data.sql` – sample seed data for departments, employees, clients, products, and sales.
- `queries.sql` – analysis queries (joins, aggregates, window functions, CTEs, views, etc.).

Run order:
1. Create database `company_analytics` in MySQL.
2. Run `schema.sql`.
3. Run `data.sql`.
4. Explore with `queries.sql`.
